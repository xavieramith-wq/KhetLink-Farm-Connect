# KhetLink

Agricultural Machinery Rental Platform connecting farmers and machinery owners.

## Tech Stack
- Frontend: React + Vite + Tailwind CSS
- Backend: Python Flask
- Database: MongoDB Atlas

## Getting Started

### Phase 1: Setup

#### Backend Setup
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

#### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

Now the application is ready for Phase 1!
